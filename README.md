# Rocket

This repository contains all the 3D printable files, flight tips, and documentation for the model rockets I’ve designed, printed, and launched.

## Rocket Models
- **V1** – Basic model
- **V2** – Beta (recommended)

### Recommended Motors
- **Both models**: A6-3 motors
- **V2 model**: Also compatible with B6-2 motors

## Launch Setup
The launch stand is a simple tripod design with a vertical launch rod. I use a standard wired launch controller. The igniter (fuse) is connected to the motor following normal model rocket safety procedures.

## 3D Printing Instructions
- **Material**: Bambu Lab PLA Aero (highly recommended)
- Print settings: Use standard PLA settings with 3 walls and 10–16% infill
- After printing, **sand all rough edges** for a smooth finish and better aerodynamics

## Flight Tips for Better Performance
For more stable and higher flights:
- Add **launch lugs** (or rail buttons) near the bottom of the rocket body
- Ensure proper fin alignment and sufficient nose weight for stability
- My personal best altitude so far: **~100 meters**

## Recovery System
- Main parachute: **100 cm** wide
- Successfully recovers both V1 and V2 rockets
- Parachute is attached to the nose cone with a nylon cord
- **Packing method**: Roll the parachute tightly, then fold it in half before inserting into the rocket body

## Filming & Photography
I capture most launches with multiple cameras:

- **Ground Camera**: DJI Osmo Action 5 Pro on a small tripod placed **15 cm** from the launch rod (works great at this distance)
- **Aerial Footage**: Drone flying overhead
- **Still Photos**: Canon camera
- **Future Plans**: FPV chase drone for tracking shots

## Contents of this Repository
- STL files for both rocket versions
- Parts (nose cones, fins, etc.)
- Photos and flight videos

## Safety First
Always follow local model rocket safety guidelines (NAR safety code recommended). Launch in open areas away from power lines, trees, and people.
